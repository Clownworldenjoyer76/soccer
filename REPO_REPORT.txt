### 2. Formula verification — PASS

Production formulas in `docs/win/soccer/scripts/03_edges/build_edges.py` are:

```text
fair_odds = 1 / p
EV        = p × (odds - 1) - (1 - p)
edge      = odds / fair_odds - 1
Kelly     = ((p × odds) - 1) / (odds - 1)
```

Kelly is clipped at zero. Totals/BTTS intentionally make `edge = EV`; it is not an independent signal.

I independently recalculated all **3 scored Bundesliga 1X2 selections** currently present historically.

| Check     | Maximum absolute error |
| --------- | ---------------------: |
| Fair odds |                **0.0** |
| EV        |           **8.33e-17** |
| Edge      |           **8.33e-17** |
| Kelly     |           **8.33e-17** |

**Parity: PASS.**

No EV/Kelly/fair-odds/edge math change is supported.

I also independently recalculated Brier score, log loss and RPS for a stored Bundesliga model-evaluation row; all three reproduce the production values exactly.

### 4. Current raw production signal

For Bundesliga 1X2, the earliest actual production prediction is the ML output, not the manually supplied `home_prob/draw_prob/away_prob`.

Those manual probabilities are a **parallel external signal** and are not inputs to the production Bundesliga model. Therefore:

```text
manual probability → ML probability
```

is **not** a production transformation and must not be tested as though it were.

Current all-match Bundesliga production ML evaluation:

| Signal                |  N |      Brier |   Log loss |        RPS |
| --------------------- | -: | ---------: | ---------: | ---------: |
| Manual/raw comparator | 49 | **0.5534** | **0.9376** | **0.2008** |
| Production ML         | 56 |     0.5757 |     0.9724 |     0.2070 |

**Do not conclude that ML is worse from this table.** The populations differ, 49 versus 56 observations. That violates the identical-population requirement.

This comparison remains **UNRESOLVED pending common-observation testing**.
